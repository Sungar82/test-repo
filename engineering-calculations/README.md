
# Engineering Calculations

This folder contains engineering calculation methods, formulas, assumptions, and worked examples.

## Planned calculations

- Pipe outside diameter and geometry
- Roller height and roller positioning
- Chord length and angles
- Sheet metal calculations
- Engineering formulas and unit conversions

## Calculation requirements

Each calculation should document:
- Input values and units
- Formula used
- Calculation steps
- Final result and units
- Assumptions and limitations

## Validation

Check formulas and results against engineering references or independent calculations before using them for manufacturing.
